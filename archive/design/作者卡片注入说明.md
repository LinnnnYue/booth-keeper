# BoothKeeper「作者卡片」注入说明

> 说明：本项目里的「作者卡片」指设置页「☕ 支持作者」这个署名 / 赞助区块。它是在**构建与发版流程**中，被同步注入到「软件界面 + GitHub README + 安装包尾页」三处的，三处共用同一张 `assets/donate_qr.png`。

## 一、作者卡片在项目的哪几处

| 注入位置 | 文件 | 形态 |
| --- | --- | --- |
| 软件设置页 | `pages/settings_page.py`（约 103–161 行） | 应用内 UI 卡片（QLabel 显示二维码 + 富文本链接） |
| GitHub README | `README.md`（约 169–187 行） | 文档卡片（`<img src="assets/donate_qr.png">`） |
| 安装包尾页 | `BoothKeeper.nsi`（约 53–55 行） | 提示「查看 README（含微信赞助码）」 |

> 注意：项目里**没有**独立的自动化「工作流」文件（无 `.github/workflows`）。所谓「注入」，是通过构建 + 发版流程把同一张图同步到这三处。

## 二、怎么「注入」——两种形态

### 形态 A：应用内卡片（PySide6）

核心三行：

```python
qr_path = asset_path("donate_qr.png")          # 1. 定位图片（开发态 assets/，打包态 _MEIPASS/assets/）
pm = QPixmap(qr_path).scaled(140, 140, ...)    # 2. 加载并缩放
qr_label.setPixmap(pm)                          # 3. 塞进 QLabel 显示
```

链接不用按钮，用富文本 `<a href>`，并设置 `setOpenExternalLinks(True)` 即可点击跳转。

### 形态 B：文档 / HTML 卡片

两种引用方式：

- README 用**文件引用**：`<img src="assets/donate_qr.png" width="120">`（依赖仓库里这张图）
- 单文件 HTML / 邮件用 **base64 内嵌**（不依赖外部文件，见第五节）

## 三、怎么设置（改动步骤）

1. **换图**：直接替换 `assets/donate_qr.png`（开发模式放 `assets/`，打包后随 exe 进 `_MEIPASS/assets/`）。
2. **改链接 / 文案**：`settings_page.py` 里的爱发电链接 `https://afdian.com/a/LinnYue`、GitHub 链接、标题「☕ 支持作者」、提示文案；以及 `README.md` 里的同名链接。
3. **自动同步**：设置页和 README 引用的是**同一个文件**，换一次图两处一起变，无需改两遍。
4. **重打包**：`PyInstaller --clean` 重打 onefile exe → `makensis BoothKeeper.nsi` 安装包 → zip 便携包。

### 模板 C｜base64 内联 HTML 卡片

已生成自包含示例文件 `author_card_template.html`（双击即可预览，当前收款码已内嵌）。复制整个 `.author-card` 块即可注入任何 HTML 产物，各部分作用见文件内注释：

## 五、base64 图片是什么

- **概念**：把图片的二进制字节，按 base64 规则编码成一长串**纯文本（ASCII）**。这样图片就能直接写进 HTML / CSS / JSON 里，不再是一个独立 `.png` 文件。
- **为什么用**：当「工作流产物」是**单文件**（一个 HTML 报告、一封邮件、一个要到处发的页面），目标环境不允许或不方便带外部图片文件时，base64 内嵌最省事——发出去就是一个自包含文件，打开即有图。
- **格式**：`data:image/png;base64,<编码串>`；SVG 用 `data:image/svg+xml;base64,<编码串>`。本项目 `theme.py` 正是用后者把主题纹样 SVG 内嵌进 QSS。
- **怎么生成**（换图时重跑）：

  ```bash
  python -c "import base64;print('data:image/png;base64,'+base64.b64encode(open('donate_qr.png','rb').read()).decode())"
  ```

  把整段输出粘进 `<img src="...">` 即可。

- **注意**：base64 比原图大约 **+33%** 体积。二维码小图无所谓；大图慎用，会明显拖慢加载。
