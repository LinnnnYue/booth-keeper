# Booth Keeper v1.3.7 — 实验检索拖放强化

## 修复
- **输入框显式支持文件/文件夹拖放**：实验检索页的输入框现在使用定制的拖放控件，拖入文件或文件夹会自动把 `file://` 路径填入输入框（支持多文件/文件夹、自动换行），不再依赖 Qt 默认行为。彻底解决「文件/文件夹拖不进去」的问题。

## 说明
v1.3.6 的双击跳转、归档修复均保留。

- **Windows 安装包** `BoothKeeper_Setup_1.3.7.exe`（77 MB）
- **zip 解压即用** `BoothKeeper_portable_v1.3.7.zip`（76 MB）
