# Booth Keeper v1.4.1 — 封面快速失败 + 直连兜底 + 设置自动保存

## 修复
- **归档很慢 → 三件套缺失（根因）**：`download_cover` 原为 `timeout=60 / retries=3`，
  代理抖动时单个商品要卡 **~186 秒**，批量归档直接卡死，最终超时失败 → 三件套缺失。
  现改为 `timeout=20 / retries=2`（单商品最坏 ~42 秒，提速 4 倍以上）。
- **封面下载直连兜底**：`booth.pximg.net` 是图片 CDN，不少代理节点只放行 `booth.pm`
  而卡住 pximg。代理失败时自动摘掉代理直连重试一次，成功率大幅提升。
- **封面失败不再静默**：归档结果带 `cover_ok` / `icon_ok`，日志明确提示
  「⚠ 封面缺失 → 三件套不完整（可到目录巡检页点『修复三件套』补齐）」。
- **设置自动保存**：改动即存（代理开关 / 代理 URL / Cookie / 归档根目录 / 自动更新），
  不再需要手动点「保存设置」，避免重开后回到默认值。

## 说明
- 本体下载成功即算归档成功，封面属非关键资源，失败不阻塞归档。
- 三件套缺失可随时到「目录巡检」页点「修复三件套」补齐。
- v1.4.0 的归档 AttributeError 修复、拖放支持等均保留。
