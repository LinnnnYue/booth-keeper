# Booth Keeper v1.3.8 — 实验检索归档修复（拖入文件真正移动归档）

## 修复
- **归档不动文件（根因）**：修复 `file:///X:/...`（三斜杠）路径解析时残留前导 `/`，导致源文件 `exists()` 判定失败、兜底不生效，文件始终没有被移动归档。现已正确解析，拖入的文件会在「归档选中」时被真正**移动归档**并做三件套（cover / 图标 / 说明）标准化处理。
- **兜底逐行处理**：输入框存在多行/多文件时，逐行解析真实存在的路径作为移动源。
- **崩溃修复**：未找到源文件的提示弹窗不再因 `skipped` 列表为数字而崩溃。

## 说明
v1.3.7 的显式文件/文件夹拖放、双击跳转均保留。
