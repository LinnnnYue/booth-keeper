# Booth Keeper v1.3.6 — 实验检索 Bug 修复

## 修复
- **双击结果跳转浏览器**：搜索结果条目现在支持双击，自动在浏览器打开 BOOTH 商品页（`booth.pm/ja/items/{id}`），方便核对是否正确匹配。
- **归档不动文件修复**：当文件不在 BOOTH 库内（如从 Downloads 拖入），「归档选中」现在会用输入框里的原始文件路径作为源，将文件搬入正确的 BOOTH 归档目录，而非只建空目录。

## 说明
v1.3.5 功能与图标不变，仅修复实验检索页的两个交互 Bug。
