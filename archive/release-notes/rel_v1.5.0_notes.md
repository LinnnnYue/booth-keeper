# Booth Keeper v1.5.0 — 实验检索智能升级（R17）

## 全量学习结论（306 库内商品 + unity 样本端到端验证）
- 纯文件名直接搜索命中率 **~37%**；+包内信号补充到 **~43%**
- 中文文件名搜不到（BOOTH 日文站）→ 会提示 + 建议用编号
- 无法高自动化 → 用「置信分级」把最可能的排最前，人工只确认低置信

## 新增功能
- **包内多信号提取**：拖入文件/文件夹，自动解析 zip / unitypackage 内部（`pathname`），
  提取「外层名 + 包内商品名 + 作者名」（如 `Assets/BLVK/NailRing/` → 作者 BLVK + 商品 NailRing）
- **作者名过滤加权**：BOOTH 店名/品牌命中作者名 → 评分 +0.25（最强过滤信号）
- **结果打分排序**：名称 token 覆盖率（对 CJK/日文友好）+ 作者命中，高分置顶
- **置信分级显示**：`[100% 高置信]` 绿可直接归档 / `[50% 中置信]` 黄建议核对 / 低置信警告
- **严谨下架判定**：只有「连通性探针通过 + 商品页确实 404」才判已下架，
  归入 `BOOTH\已下架商品\{ID}`；网络不可达时一律 unknown、不误判
