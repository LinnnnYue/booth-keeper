# Booth Keeper v1.5.4 — 拖拽分栏（R21）+ force 重归档安全留档（R22）

## 新增：拖拽分类页左右分栏
- 界面左右分两栏：**左 = 待归档队列**，**右 = 已归档记录**。
- 归档成功的项**立即从待归档队列移入右栏**（不再留在原地）；失败项标红留在左侧，可单独重试。
- 右栏**跨会话留存**，最新归档的记录排在最上方，重启软件不丢。

## 修复：归档完成仍留在队列（用户实踩）
- 旧 bug：归档完成后商品仍留在待归档队列 → 再次点归档弹「目录已存在要替换」→ 确认后变成**空文件夹**、原商品进回收站。
- 根因：拖拽入队时未把源路径写入列表项 data，后续「按 data 匹配移出队列」全部落空。
- 本次在入队时补上 data 写入，成功项可正常移出；同类匹配逻辑全部复核通过。

## 安全化：force 重归档不再「先清旧目录」
- 之前目标目录已存在时，走「改名备份 → 归档 → 回收旧档」，中途失败可能丢数据。
- 现在改为**同位置日期留档**：在目标目录内新建 `旧版本_2026-09-07_163746` 子目录，
  旧内容整体移入（**不删、不进回收站，永久留档**），新归档内容落目录根，封面/图标随后刷新。
- 源文件缺失时先还原已留档内容再报错，绝不产生空目录；留档中途失败自动回滚已移入项。
- 确认弹窗文案同步改为「旧内容会留档在「旧_日期」子目录，不删除」。

## 其他
- 应用/安装包图标**换回最初图标**（此前 1.3.4 换成了 Reimu 蛋，本版还原为 app_icon）。
