# Booth Keeper v1.5.1 — 损坏压缩包自动识别与重下（R18 修复）

## 修复：『已存在就跳过』吞掉半截文件（本次 bug 根因）
- **问题**：链接页跳过逻辑只查 `存在 + size>0`，断下载残留的半截 zip 被当作已完成。
  换节点重跑 → 全部「已存在跳过」，但打开即「压缩包已损坏」。
- **修复**：新增 `booth_core.is_corrupt_package` 完整性校验（zip 读中央目录 / unitypackage gzip+tar），
  链接页「存在但损坏」→ 视为缺失重新下载；下载后仍校验，坏则报「下载失败或仍损坏」。
- 全库新增 `scan_corrupt_in_library` 公共扫描接口。

## 顺手修复：unitypackage 完整性误判（深度学习发现的连环 bug）
- `tarfile.TarFile` 不是迭代器（Python3），且 `booth_core` 漏 `import gzip` —
  所有 unitypackage 被误判损坏。两处已修复，避免后续版本误删误下。
