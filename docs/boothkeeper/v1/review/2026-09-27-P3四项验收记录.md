   性质是「静默降级为无更新提示」，不产生错误的状态承诺，故未纳入本次 8 处加固范围。

   够用；若将来需同时落盘，再考虑改为 handler 列表。
4. **无文件日志**：按 §2.1「不做什么」明确不做，留作可选扩展。

   网络异常会直接抛出而非返回 `status=err`。属既有行为，未在本次改动；
   当前由 2.3 的基类兜底捕获并经 2.1 上报，用户可见。**若后续要改，属独立立项。**
