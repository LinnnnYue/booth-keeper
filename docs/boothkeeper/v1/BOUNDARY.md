- **能做**: 读取、遍历、巡检、统计资产库目录结构；在用户当次明确要求归档操作时执行移动（须二次确认 + 可回滚）。
- **不能做**: 把真实资产库当测试沙盒；任何未获当次授权的移动、重命名、删除、覆盖；对 `G:\Lin_File\BOOTH` 做批量破坏性操作。

- **出处**: 2026-09-27 主上委派接入 devskill 时确立；镜像既有设计意图（`archive_util.py:236-334` 的留档与还原逻辑）。

### B-3 版本号三处同步（登记：2026-09-27 · 登记人：拉斐尔）

- **能做**: 发版时按固定顺序更新三处并逐项核验。
- **不能做**: 只改其中一处就发版；版本号与实际安装包不一致。
- **原因**: 项目历史上出现过发版事故（R24 黄色图标根治、1.5.6 收款码替换），每次都要靠独立发版 commit 补救。版本号不同步会让「检查更新」误判、让用户装到错版本。
- **反复修改史**: 由 `rel_v1.5.5_notes.md`（「版本号/安装包版本/发版记录」三件套）与 `rel_v1.5.6_notes.md` 反复强调而来，2026-09-27 正式登记为红线。
- **出处**: `git log` 中 `1f14aab`、`c9bd5ab`、`58b82b1` 三个发版 commit 的提交信息。
